# Reverification Evidence

Files in this directory capture repo-local evidence that supports verification
concerns and their resolutions. Each file should:

- Use a descriptive, concern-specific filename.
- Reference the source artifacts (logs, diffs, or summary files).
- Keep links relative to the repository root when possible.

## Decisions

The [decision record](DECISIONS.md) contains the dated verification rulings and
commands for reproducing the historical auth coverage baselines.

Completed issue ledgers cite the former root path. Their references resolve in
the [original root decision record](https://github.com/stranske/Workflows/blob/2e8642102b7cefa72523795ef1b17bf1b52b4b18/DECISIONS.md).
