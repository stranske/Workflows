# LLM Model Evaluation for Task Completion Analysis

**Historical snapshot (February 2026).** The model names, availability claims,
rankings and recommendations in the [original evaluation](https://github.com/stranske/Workflows/blob/0c0334c6e92588c158f1c9362f1409062477de09/docs/LLM_MODEL_EVALUATION.md)
record a past analysis and are not the current selection policy.

Use the [auxiliary model selection policy](MODEL_SELECTION_POLICY.md) for the
current decision process and [model management guide](MODEL_MANAGEMENT.md) for
catalog discovery. The selected model and review dates are recorded in
[`config/model_registry.json`](../config/model_registry.json) and
[`config/llm_slots.json`](../config/llm_slots.json).
