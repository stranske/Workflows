# Model Selection Framework

**Historical design only.** The [original framework](https://github.com/stranske/Workflows/blob/0c0334c6e92588c158f1c9362f1409062477de09/docs/MODEL_SELECTION_FRAMEWORK.md)
records an estimated-score proposal and model examples. It is not the implemented
selection procedure.

Use the [auxiliary model selection policy](MODEL_SELECTION_POLICY.md) for the
current constrained, evidence-based process and the [model management guide](MODEL_MANAGEMENT.md)
for catalog discovery. Registry and slot state are in
[`config/model_registry.json`](../config/model_registry.json) and
[`config/llm_slots.json`](../config/llm_slots.json).
