# Pair-generation regression

The first real production receipt is written before the peer changes inputs. The peer retries against the newer generation; the earlier stale output must fail final pair validation and be preserved with its original receipt. Five cases cover findings, provenance, protocol, prior-turn and output bytes. The original production source fails all five assertions; the correction passes. No live providers are invoked. Commands, exits, hashes and scope are in receipt.json; raw console output is retained here.
