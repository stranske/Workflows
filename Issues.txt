1. Add Trend reference pack support to Codex runs: 
 ## Why

 You want Codex working inside Portable Alpha to have local, file-level access to Trend’s Streamlit LangChain implementation as a baseline. The cleanest approach is a reference pack automatically checked out into the workspace during Codex runs (keepalive/autopilot), without asking the agent to curl or fetch external content.

 ## Scope

 - Update Workflows `reusable-codex-run.yml` so it can optionally materialize one or more reference packs into the consumer repo workspace from a config file stored in the consumer repo.
 - Append a short “Reference Pack” section to the Codex prompt indicating where the pack lives locally.

 ## Non-Goals

 - Create or modify consumer repo workflows (`.github/workflows/**`) in this issue
 - Index or summarize the entire Trend repo (keep packs sparse and targeted)

 ## Tasks

 - [ ] In `stranske/Workflows` update `.github/workflows/reusable-codex-run.yml` to detect a consumer config file (recommend: `.github/reference_packs.json` to avoid YAML parsing dependency)
 - [ ] Implement a checkout step per pack using `actions/checkout` with `sparse-checkout` and `path: .reference/<pack_name>`
 - [ ] Ensure `.reference/**` is excluded from git status (add to `.git/info/exclude` similarly to `.workflows-lib`)
 - [ ] Create a small generated summary file (ex: `.reference/REFERENCE_PACKS.md`) listing:
   - pack names
   - repo/ref
   - local path
   - key files included
 - [ ] Modify the “Assemble prompt” step to append `.reference/REFERENCE_PACKS.md` when present
 - [ ] Add a minimal self-check step that fails early if config is malformed (clear message), but does not fail runs when the config file is absent

 ## Acceptance Criteria

 - [ ] When a consumer repo includes `.github/reference_packs.json`, Codex runs have `.reference/<pack>/...` populated before Codex executes
 - [ ] The Codex prompt includes a “Reference Pack” section pointing to those local files
 - [ ] When the config file is absent, behavior is unchanged

 ## Implementation Notes

 - Keep pack checkout after dependency install is fine, but ensure it occurs before “Clean workspace for Codex” or extend that step to also exclude `.reference`.
 - Prefer config format:
   - JSON: easiest to parse without extra deps
   - Example schema: `{ "packs": [ { "name": "...", "repo": "stranske/Trend_Model_Project", "ref": "<sha>", "paths": ["..."] } ] }`
 - Trend’s default branch is `main`; for reproducibility, packs should pin to a commit SHA.
